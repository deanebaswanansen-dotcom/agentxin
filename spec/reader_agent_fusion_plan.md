# PLAN: Reader Source Parity + Agent Fusion

## 目标

以 `C:\Users\my147\Desktop\novel-comic-reader` 为功能和视觉源，把 `agentxin` 的书架改成完整阅读应用模式，再叠加 Agent 改写和资料提取。

## 实施顺序

1. 源应用盘点
   - 功能：TXT / MD / EPUB / HTML / JSON / PDF / CBZ / 图片 / 图片文件夹 / Markdown 文件夹。
   - 书架：首页导入、继续阅读、统计、书架、最近阅读、路径信息、刷新恢复。
   - 阅读：目录、书签、搜索、章节 range、上一章 / 下一章、阅读设置、主题、沉浸模式、漫画连续滚动、PDF 原版查看。
   - 视觉：纸质浅色底、墨绿色主色、圆角面板、首页 hero + drop panel、书封网格、聚焦阅读器。

2. 解析层补齐
   - 扩展 `readerImport` 到 EPUB、PDF、CBZ、图片和文件夹输入。
   - 小说输出章节，漫画输出页面，PDF 输出 object URL 所需二进制。
   - Markdown 文件夹按路径自然排序并合成文集。

3. 书架与路径能力
   - 完整书籍内容进入 IndexedDB，localStorage 只保存会话、最近阅读、书签、设置等轻量状态。
   - 书架保留来源路径、目录名、媒体类型、封面、章节 / 页数统计。
   - 分类包含全部、当前项目、小说、漫画/PDF、文件夹扫描、已接入 Agent、最近阅读。
   - 输出目录保留名称；浏览器授权存在时写入目录，未授权时下载。

4. UI 重排
   - 书架页按源应用结构重做：header、hero 导入区、继续阅读、统计、书架网格、最近阅读。
   - 阅读页按源应用结构重做：顶部工具条、目录/书签面板、元信息、搜索、章节 range、内容卡片、设置面板、沉浸模式。
   - Agent 作为阅读页内工作模式出现，保持选中文段重写、应用、世界观/大纲/人物提取。

5. 验证
   - 单元测试覆盖解析、书架、书签、设置、UI 交互。
   - 前端 `typecheck`、`test`、`build`。
   - 后端 `typecheck`、`test`、`build`，确认 Agent API 未破坏。
   - 浏览器实测：源应用截图对比、融合版导入/阅读/搜索/书签/设置/沉浸/Agent 改写。
   - 清理临时导入文件、临时项目、浏览器 smoke 文件。

## 验收线

- 书架模式是顶层应用，不是框或抽屉。
- 源应用 README 中列出的阅读格式全部能进入对应阅读视图。
- 源应用首页和阅读页的主要布局、间距、卡片层次和阅读宽度在融合版中可见。
- 小说阅读保留 Agent 改写和资料提取；漫画/PDF 保留阅读，不显示文本改写入口。
- 控制台 0 error / warning，桌面和移动视口无水平溢出。
