# UI重构与自由AI对话功能

## Context

用户反馈当前UI存在三个核心问题：
1. **导航混乱**：右侧4个tab（伴写/Agent/蓝图/设置）过多，左侧项目列表+4个资料tab也很拥挤
2. **缺少自由AI对话**：现有"伴写"必须选中章节且只能续写/改写/润色，无法自由讨论剧情、角色、世界观
3. **UI臃肿**：设置面板占据了一个常驻tab位，但实际很少使用

用户确认的设计方向：
- 将"伴写"升级为**统一对话面板**：未选章节时可自由讨论，选中章节后自动进入写作模式
- 设置改为**弹窗/抽屉**，释放一个tab位

## 改动后的信息架构

```
右侧面板（改动后 3 tab）:
├── 💬 AI对话（统一面板）
│   ├── 无章节 → 自由讨论（剧情/角色/世界观/写作技巧）
│   └── 有章节 → 写作模式（续写/改写/润色 + 自由提问）
├── 🔮 Agent（保持不变）
└── 🗺️ 蓝图（保持不变）

设置（改为弹窗）:
└── ⚙️ 齿轮图标 → 弹出SettingsPanel
```

## Task 1: 后端新增自由对话API

**目标**：新增 SSE 流式路由 `POST /api/projects/:projectId/chat`，支持自由对话

**涉及文件**：
- `backend/src/types/index.ts` — 新增 `FreeChatRequestBody` 类型
- `backend/src/routes/freeChatRoutes.ts` — 新建路由（~120行）
- `backend/src/services/freeChat/FreeChatService.ts` — 新建服务（~150行）
- `backend/src/index.ts` — 注册新路由

**API设计**：
```typescript
// POST /api/projects/:projectId/chat (SSE)
interface FreeChatRequestBody {
  message: string;
  context?: 'plot' | 'character' | 'world' | 'writing' | null;
  chapterId?: Id;          // 可选，提供章节上下文
  attachedSettingIds?: Id[];  // 可选，附加设定条目
  sessionHistory?: ChatTurn[];  // 前端维护的对话历史
}
// 响应格式复用现有 SSE 帧协议 (event: delta/done/error)
```

**实现要点**：
- 复用现有 `LlmProxy` 做流式调用
- 根据 `context` 字段动态组装系统提示词
- 将项目设定（人物/世界观/大纲）注入上下文
- 错误处理复用 `errorMapping.ts`

## Task 2: 前端统一对话面板

**目标**：将现有 `ChatPanel.tsx` 重构为统一的 `UnifiedChatPanel.tsx`，支持两种模式

**涉及文件**：
- `frontend/src/components/UnifiedChatPanel.tsx` — 新建（~500行），合并自由对话+写作辅助
- `frontend/src/components/ChatPanel.tsx` — 废弃/删除
- `frontend/src/api/apiClient.ts` — 新增 `freeChat.stream()` 方法
- `frontend/src/types/index.ts` — 新增 `FreeChatRequestBody` 类型

**组件设计**：
```tsx
interface UnifiedChatPanelProps {
  projectId: Id;
  chapterId?: Id | null;        // null=自由模式
  editorContent?: string;        // 写作模式需要
  selection?: EditorSelection;   // 写作模式需要
  onAdopt?: (result: AdoptionResult) => void;  // 写作模式的采用回调
  onError?: (error: unknown) => void;
}

// 内部自动判断模式:
// - chapterId 存在 → 写作模式（保留续写/改写/润色 + 新增自由提问）
// - chapterId 不存在 → 自由讨论模式
```

**自由讨论模式特性**：
- 对话主题快捷标签：剧情/角色/世界观/写作技巧（可选，不选=综合）
- 保留完整对话历史，可清空
- 流式渲染AI响应
- 无"采用"按钮（纯讨论）

**写作模式特性**：
- 保留现有续写/改写/润色能力
- 新增"自由提问"操作类型（可以问关于当前章节的任何问题）
- 保留"采用"按钮
